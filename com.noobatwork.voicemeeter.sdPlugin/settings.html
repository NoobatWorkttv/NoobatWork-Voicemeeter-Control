NoobatWork · Voicemeeter

Potato: Hardware Input 1–5, Virtual Input 1–3 oder Ausgang A1–A5 / B1–B3.

Erkannt werden aktive Windows-Audiositzungen – auch auf Voicemeeter VAIO3. Anwendungen können erst erscheinen, nachdem sie einen Ton ausgegeben haben. Einstellung gilt für alle Audiositzungen derselben EXE.

Leer lassen für die Standardbezeichnung.

Wie stark die Lautstärke bei jedem Tastendruck verändert wird.

Kompakt-Mixer – eine Taste pro Kanal: Kurz tippen = lauter, gedrückt halten = leiser. Die Mute-Geste wird weiter unten pro Taste ausgewählt.

Jede Mixer-Kachel kann einen anderen Input oder Ausgang steuern. Faderposition und echter Audiopegel werden auf der Taste live angezeigt.

Beim neuen Modus macht jeder kurze Tipp sofort lauter – auch mehrmals schnell hintereinander. Für Mute einmal kurz tippen und innerhalb von 280 ms den zweiten Tipp mindestens 350 ms halten. Ein einzelner langer Druck macht weiterhin leiser.

Standard ist die bisherige Doppeltipp-Steuerung. Du kannst den Modus für jede Taste einzeln ändern.

Fünf Segment-Aktionen nebeneinander anlegen. Auf allen fünf Tasten denselben Kanal und Pegelbereich wählen, aber Position 1–5 vergeben. Jede Taste setzt einen festen Lautstärkewert.

Standardwerte: −40, −30, −20, −10 und 0 dB.

Die Einstellungen gelten nur für diese Taste und werden automatisch gespeichert. Änderung am Mixer wird live übernommen.
